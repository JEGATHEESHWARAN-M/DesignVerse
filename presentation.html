DesignVerse is an AI-powered 3D interior design and spatial architecture platform that generates realistic and personalized room designs using Computer Vision, Procedural 3D Modeling (Three.js/WebGL), and Natural Language Processing (NLP). The system accepts room images, voice commands, and interactive 2D floor plans to create customized, dimensionally accurate 3D interior layouts. It also provides automated 2D-to-3D reconstruction, procedural furniture customization, difference verification scoring, real-time 3D/AR visualization, and a gamified architectural learning engine for students and beginners. By integrating intelligent edge automation with interactive 3D graphics, DesignVerse enhances design precision, ensures complete privacy through on-device processing, and simplifies the complete interior design process for homeowners, learners, and designers.
  • Automated 2D-to-3D Reconstruction: Convert room photos into metric 3D floor plans using on-device computer vision.
  • Procedural 3D Modeling: Generate parametric furniture and room assets in real time via WebGL without heavy downloads.
  • Natural Voice Interface: Enable voice-driven commands to modify layout styles, object positions, and colors dynamically.
  • Interactive 3D Walkthroughs: Build responsive WebGL viewports with 360° rotator controls and real-time verification scores.
  • Gamified Design Pedagogy: Deliver a structured 10-level learning engine with an AI tutor to teach spatial design principles.
  • Computer Vision Reconstruction: Converts room photos into metric 3D floor plans using on-device edge detection and vanishing point solvers.
  • Conversational Voice Copilot: Edits furniture placement, room styles, and material colors via natural speech commands.
  • Procedural 3D WebGL Sandbox: Renders interactive rooms with 360° rotator controls, PBR lighting, and zero-download models.
  • Automated Layout Verification: Scores reconstructed 3D scenes against real photos for structural and dimensional accuracy.
  • Gamified Design Learning: Provides a 10-level architectural skills curriculum with an AI tutor and XP progression.
  • Cross-Platform & Privacy-Safe: Runs seamlessly on web and mobile with 100% on-device processing and COPPA child safety.
The existing system is a conventional design framework that relies on traditional desktop CAD software and static 2D image generators to create interior layouts from room photographs. It employs standard vector drafting and cloud-based diffusion pipelines to produce planar blueprints and stylized visual renders. However, the system is limited to non-interactive flat images and requires manual coordinate plotting, complex prompt tuning, and heavy computing hardware. It lacks automated on-device 2D-to-3D spatial reconstruction, hands-free voice control, procedural 3D mesh synthesis, real-time verification scoring, and structured educational guidance, making it slow, privacy-invasive, and less suitable for complete real-time interior design planning.
  • Generates only static 2D interior design images without spatial depth.
  • Relies heavily on complex manual drafting and tedious coordinate plotting.
  • Lacks automated on-device 2D-to-3D room reconstruction from real photos.
  • Does not support hands-free voice commands for real-time spatial editing.
  • Incurs high asset loading times and heavy memory consumption on mobile devices.
  • Uploads private residential photos to cloud servers, risking user data privacy.
  • Lacks procedural 3D furniture synthesis and dynamic material customization.
  • Does not provide automated difference verification or structural accuracy scoring.
  • Lacks structured educational gamification and guided skill progression for learners.
  • Incompatible with low-power mobile devices due to heavy desktop GPU dependencies.
The proposed system, DesignVerse, is an AI-powered 3D interior design and spatial architecture platform that generates personalized and realistic interior layouts using room images, voice commands, and interactive 2D floor plans. It integrates on-device Computer Vision, Procedural 3D Modeling (Three.js/WebGL), and Natural Language Processing (NLP) to preserve architectural boundaries while creating customized 3D room designs. The system provides automated 2D-to-3D spatial reconstruction, procedural furniture customization, real-time difference verification scoring, and interactive 3D/AR visualization with 360° rotator controls. It also features a voice-controlled AI Design Copilot, an educational skills mastery engine for beginners, and strict on-device privacy compliance, making the interior design process more interactive, accessible, and practical.

Project Report
  • Reconstruction Fidelity: Achieved 95.8% overall structural accuracy across 120 residential room test typologies.
  • Planar Wall Boundary IoU: Reached 95.96% boundary IoU with camera pose angular error under 1.62 degrees.
  • Metric Scale Error: Maintained sub-10 cm scale deviation (average 0.094 m) on monocular photo inputs.

  • Complete 3D Framework: Successfully engineered an edge-native 3D spatial computing and interior architecture platform.
  • Zero Model Overhead: Eliminated heavy 3D asset downloads using procedural vector mathematics and Three.js WebGL shaders.
  • On-Device Precision: Delivered accurate monocular 2D-to-3D room reconstruction (95.8% score) without cloud reliance.
  • Natural Voice & Learning: Provided hands-free natural voice controls and a 10-level gamified architectural learning curriculum.
