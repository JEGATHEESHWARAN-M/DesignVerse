# 🗺️ DesignVerse Kids — 2D Floor Plan Learning

## 1. Bird's-Eye View Concept
In Unit 8 (Floor Plan Explorer), children are introduced to the concept of architectural drawings:
> *"A floor plan is like a map of a room seen from high above by a soaring bird!"*

## 2. Interactive Child 2D Planner
- **Canvas-based 2D Grid:** High-DPI canvas displaying room dimensions (width & length in meters).
- **Wall Drawing:** Drag to draw internal partitions and room boundaries.
- **Doors & Windows:** Stamp doors and windows onto walls with clear swing arcs.
- **Furniture Symbols:** Drag 2D furniture icons (bed, table, chair, sofa) into position with real collision checking.
- **Immediate Visual Dimensioning:** Dimension markers display measurements in child-friendly meters.
